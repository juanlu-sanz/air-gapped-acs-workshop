RHACS: Security Lifecycle Workshop

Security reporting, compliance posture, vulnerability management, and risk mitigation on OpenShift

This workshop covers the full security lifecycle with Red Hat Advanced Cluster Security for Kubernetes (RHACS). You will create and schedule vulnerability reports, integrate the Compliance Operator with CIS and STIG benchmarks, configure delegated image scanning for registries that Central cannot reach, deploy intentionally vulnerable workloads to triage CVEs, enforce security policies as code, remediate vulnerabilities, and integrate RHACS into CI/CD pipelines. The exercises run on two OpenShift clusters hosted on AWS: one hub cluster running ACS Central, and one secured cluster with a local registry.
