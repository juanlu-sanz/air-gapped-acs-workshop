== Security reporting, compliance posture, and scanning in disconnected environments

This workshop covers three areas of Red Hat Advanced Cluster Security for Kubernetes (RHACS). You will create and schedule vulnerability reports, integrate the Compliance Operator with CIS and STIG benchmarks through tailored profiles, and configure delegated image scanning for a registry that ACS Central cannot reach directly. The exercises run on two OpenShift clusters hosted on AWS: one hub cluster running ACS Central, and one secured cluster simulating an air-gapped environment.
